## Эксперимент 1. Накопление массивов byte

Расчёт для одного шага с подстановкой чисел:
Количество массивов × элементов в массиве × байт на элемент = ... байт.
В MiB: ... / 1 048 576 = ...

| Шаг | Сохранено массивов | Расчётный объём элементов, MiB | Рабочий набор, Mib | изменения от начала, MiB |
| --: | -----------------: | -----------------------------: | -----------------: | -----------------------: |
|   0 |                  0 |                              0 |                    |                        0 |
|   1 |                  1 |                                |                    |                          |
|   2 |                  2 |                                |                    |                          |
|   3 |                  3 |                                |                    |                          |
|   4 |                  4 |                                |                    |                          |
